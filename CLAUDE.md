# FLOJAVA Marketplace Rules

## Stack

* Next.js
* TypeScript
* TailwindCSS
* Node.js

---

## Architecture Rules

* gunakan clean architecture
* pisahkan UI dan business logic
* gunakan reusable component
* gunakan folder structure rapi
* hindari logic besar di page/component

---

## Security Rules

* jangan expose API key
* semua input wajib validation
* gunakan environment variable
* sanitize user input
* jangan hardcode credential

---

## UI Rules

* responsive mobile first
* modern coffee marketplace style
* clean typography
* gunakan spacing konsisten
* gunakan reusable UI component
* hindari design terlalu ramai

---

## Coding Rules

* hindari any type
* gunakan async/await
* gunakan TypeScript strict typing
* gunakan naming yang konsisten
* hindari duplicate code

---

## Performance Rules

* optimalkan image
* minimalkan rerender
* gunakan lazy loading jika perlu
* hindari fetch berulang

---

## Review Process

Sebelum selesai coding:

1. review bug
2. review security
3. review performance
4. review responsive design
5. review accessibility
6. review clean architecture

---

## AI Workflow

Sebelum coding:

1. analisis requirement
2. identifikasi file yang perlu diubah
3. buat implementation plan
4. identifikasi edge case
5. baru implementasi

Setelah coding:

1. self review
2. cari bug
3. cari security issue
4. cek responsive layout
5. cek performance
